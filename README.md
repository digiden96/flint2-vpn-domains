# Списки доменов для раздельной маршрутизации

В репозитории находятся два готовых списка. Первый направляет выбранные сайты через VPN. Второй позволяет оставить российские сервисы на прямом подключении, а остальной интернет направить через VPN.

Он пригодится, если роутер или VPN-клиент поддерживает правила по доменам и загрузку списков по ссылке.

## Только выбранные сайты через VPN

```text
https://cdn.jsdelivr.net/gh/digiden96/flint2-vpn-domains/domains.txt
```

Добавьте эту ссылку в поле `Subscription URL` или его аналог и выберите режим, при котором через VPN идут только домены из списка.

## Российские сайты напрямую, остальное через VPN

```text
https://cdn.jsdelivr.net/gh/digiden96/flint2-vpn-domains/russia-domains.txt
```

Добавьте эту ссылку в поле `Subscription URL` и выберите режим исключения указанных доменов из VPN. Российские сервисы из списка пойдут через обычное подключение, а остальные сайты через VPN.

Чтобы правила по доменам работали правильно, устройства должны использовать DNS вашего роутера. Сторонний DNS или Secure DNS в браузере может мешать определению нужного маршрута.

## Как использовать на примере GL.iNet Flint 2

1. Откройте **VPN → VPN Dashboard**.
2. Выберите нужный режим:
   - **Specified Domain / IP List**, чтобы направить через VPN только сайты из `domains.txt`;
   - **Exclude Specified Domain / IP List**, чтобы оставить сайты из `russia-domains.txt` на прямом подключении, а остальной трафик направить через VPN.
3. Добавьте соответствующую ссылку как **Subscription URL**.
4. Оставьте **Allow Non-VPN Traffic** включённым.
5. Устройства должны использовать DNS роутера. Если адрес роутера `192.168.50.1`, укажите его как DNS. Secure DNS/DoH в браузере лучше отключить.

## Что входит в список

В `domains.txt` собраны сайты и сервисы, которым может понадобиться подключение через VPN. Домены берутся из проекта [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains), а сетевые диапазоны Telegram из его [официального списка](https://core.telegram.org/resources/cidr.txt). Дополнительные записи хранятся в `custom-domains.txt`.

В `russia-domains.txt` находятся российские сайты и приложения, которые могут не работать с иностранным IP-адресом. Основной источник — [UnRKN/ru-blocklist](https://github.com/UnRKN/ru-blocklist). Дополнительные записи хранятся в `custom-russia-domains.txt`.

Оба готовых файла обновляются автоматически каждый день. Ссылки для роутера используют CDN-зеркало, потому что прямой доступ к `raw.githubusercontent.com` может быть ограничен провайдером. CDN обновляет содержимое ветки с возможной задержкой до 12 часов.

## Как добавить домен

Для списка VPN откройте `custom-domains.txt`. Для российских сайтов откройте `custom-russia-domains.txt`. Добавьте домен, IP-адрес или CIDR-подсеть отдельной строкой:

```text
example.com
203.0.113.10
203.0.113.0/24
```

Домены указывайте без `https://`, адреса страницы и `*.`.

Сохраните изменение в ветке `main`, затем запустите обновление через **Actions → Update domain list → Run workflow**. Если не запускать его вручную, изменения попадут в итоговый файл при следующем ежедневном обновлении.

Изменять файлы напрямую может владелец репозитория и пользователи, которым он выдал доступ. Остальные могут предложить изменение через Pull Request.

Домены, начинающиеся с цифры, загрузчик Subscription URL на некоторых версиях GL.iNet не принимает. Такие редкие записи нужно добавить в туннель вручную.
