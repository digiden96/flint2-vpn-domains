# Список доменов для выборочной маршрутизации через VPN

Готовый список сайтов, которые можно направлять через VPN, не меняя маршрут для остального интернета.

Он пригодится, если роутер или VPN-клиент поддерживает правила по доменам и загрузку списков по ссылке.

## Ссылка на список

```text
https://raw.githubusercontent.com/digiden96/flint2-vpn-domains/refs/heads/main/domains.txt
```

Добавьте эту ссылку в поле `Subscription URL` или его аналог и выберите режим, при котором через VPN идут только домены из списка.

Чтобы правила по доменам работали правильно, устройства должны использовать DNS вашего роутера. Сторонний DNS или Secure DNS в браузере может мешать определению нужного маршрута.

## Как использовать на примере GL.iNet Flint 2

1. Откройте **VPN → VPN Dashboard**.
2. Для туннеля выберите **Specified Domain / IP List**.
3. Добавьте указанную выше ссылку как **Subscription URL**.
4. Оставьте **Allow Non-VPN Traffic** включённым.
5. Устройства должны использовать DNS роутера. Если адрес роутера `192.168.50.1`, укажите его как DNS. Secure DNS/DoH в браузере лучше отключить.

## Что входит в список

В списке собраны сайты и сервисы, которым может понадобиться подключение через VPN. Основная часть берётся из проекта [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains). Дополнительные домены хранятся в файле `custom-domains.txt`.

Готовый файл обновляется автоматически каждый день. При изменении `custom-domains.txt` пересборка запускается сразу.

## Как добавить домен

Откройте `custom-domains.txt` и добавьте домен отдельной строкой:

```text
example.com
```

Указывайте только домен, без `https://`, адреса страницы и `*.`.

Сохраните изменение в ветке `main`. Через несколько секунд обновлённый домен появится в `domains.txt`. При необходимости обновление также можно запустить вручную через **Actions → Update domain list → Run workflow**.
